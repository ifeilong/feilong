feilong 3.2.3 发布了，让Java开发更简便的工具库

1. 让你从大量重复的底层代码中脱身,提高开发效率;
1. 让你的代码`更简炼`，`易写`、`易读`、`易于维护`;

文档地址: http://feilong-core.mydoc.io/



maven 依赖配置:

```xml
<dependency>
     <groupId>com.github.ifeilong</groupId>
     <artifactId>feilong</artifactId>
     <version>3.2.3</version>
</dependency>
```


Gradle 依赖配置:

```java
com.github.ifeilong:feilong:3.2.3
```


本次升级共有 `1` 处变更, 具体参见  [3.2.3 milestone](https://github.com/ifeilong/feilong/milestone/18?closed=1)
